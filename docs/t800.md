# T800：walk 与默认训练配置，地板替换为 2 cm heightfield

本分支从 MorphMimic `main` 的 `aa40fe46a7fa995ba7a7354ad065a2c8ad64a302`
整理，包含 T800 接入所需的原生关节映射、模型资产和 walk 数据。
相对于 T800 的平面环境，`--terrain smooth_random_2cm` 只替换地板几何。

## 文件

| 路径 | 内容 |
| --- | --- |
| `src/morphmimic/robots/t800.py` | 25 原生关节、23 个有效 canonical 槽位、标称 PD 与 action scale |
| `src/morphmimic/robots/engineai_t800/` | T800 原始模型、mesh、texture、来源和 EngineAI 许可证 |
| `data/t800/walk_straight_slow_001_Skeleton9_official.npz` | EngineAI 原始 100 Hz walk，来源与 SHA256 见 `data/t800/source.json` |
| `data/t800/walk_straight_slow_001_Skeleton9_mujoco50.npz` | 训练 NPZ：50 Hz、996 帧、19.92 秒，含原生关节和完整身体状态 |
| `data/t800/subsets/walk_straight_slow.yaml` | 使用仓库相对路径的训练数据清单 |
| `src/morphmimic/env/terrains/t800_smooth_random_2cm.xml` | 地板 MJCF |
| `src/morphmimic/env/terrains/smooth_random_2cm.bin` | 已固定的 MuJoCo 高度数据 |
| `configs/t800/walk_hfield_2cm.json` | 下述 20k 启动命令的完整 `TrainCfg` 配置快照，供核对 |

## 安装和训练

```bash
git clone --branch t800 --recurse-submodules https://github.com/mothinf/morphmimic.git
cd morphmimic
uv sync
bash tools/train_t800_walk_hfield_2cm.sh
```

启动脚本等价于以下命令；从仓库根目录运行：

```bash
uv run python -m morphmimic.scripts.train \
  --robot t800 \
  --subset-yaml data/t800/subsets/walk_straight_slow.yaml \
  --terrain smooth_random_2cm \
  --iterations 20000 \
  --run-name t800_walk_hfield_2cm_20k
```

脚本末尾可追加标准训练参数，例如 `--gpu 0`。全部 67 个原有 `TrainCfg`
字段的默认值与上述 `main` 提交一致。命令仅选择机器人、数据、地板、训练长度和
运行名称。其余仍使用默认值，包括 4096 个并行环境、replay capacity 1000、
world-model batch 2048、imagination batch 4096、学习率 2e-4、H=32、k=8、
500 次 world-model 预训练迭代、`goal_anchor=reference` 和训练时 0–40 ms 随机延迟。

标称踝 PD 为 Kp=40、Kd=2。观测、奖励、终止条件、动作缩放和 33 维 context
使用基础版本。地形选项默认值仍为 `plane`；在命令中将
`--terrain smooth_random_2cm` 改为 `--terrain plane` 即可做平面对照。

## 地形定义与验证

地形为 seed 0 的高斯平滑随机高度场：网格间距 0.10 m，平滑 sigma 0.30 m，
平滑后归一化，峰谷高度差恰为 0.02 m，整体位于 z=-0.01 至 +0.01 m。
固定高度文件随仓库提交，运行时不重新生成；生成参数和 SHA256 见同目录 `source.json`。

地形范围 160 m × 160 m，覆盖默认 4096 个环境的初始网格及本 walk 轨迹。
环境原点与参考高度保持原值。mjlab 先创建原来的平面、材质和摩擦，随后场景 hook
从 XML 读取 heightfield，并仅替换原有 `terrain` geom 的类型、位置和高度数据。
机器人 XML、质量、惯量、关节范围、PD、碰撞形状、摩擦及仿真步长保持一致。

MuJoCo Warp 对 heightfield–box/cylinder 的接触点生成方式与平面不同；
即使参数一致，接触结果和训练曲线也可能变化。

```bash
uv run python -m unittest discover -s tests -v
```

测试覆盖稀疏关节映射、原有机器人映射兼容性、T800 电机参数、2 cm 高度差、
平面/heightfield 的机器人与环境参数一致性、4096 个初始点覆盖范围，
以及带高度数据的可迁移 XML 导出和重新加载。

## 导出与评估

导出仿真场景时显式传入同一地形选项，生成的 XML 会携带 heightfield：

```bash
uv run --group export python -m deploy.export_onnx \
  logs/t800_walk_hfield_2cm_20k out/t800_walk_hfield_2cm_20000 --iteration 20000

uv run python -m deploy.sim2sim.export_assets \
  --robot t800 \
  --subset-yaml data/t800/subsets/walk_straight_slow.yaml \
  --terrain smooth_random_2cm \
  --clips walk_straight_slow_001_Skeleton9_mujoco50 \
  --out out/t800_walk_hfield_assets --bake

uv run --group export python -m deploy.run \
  --deploy out/t800_walk_hfield_2cm_20000 \
  --assets out/t800_walk_hfield_assets \
  --robot t800 --clip walk_straight_slow_001_Skeleton9_mujoco50 \
  --interface motion --viewer native \
  --summary out/t800_walk_hfield_2cm_20000/eval.json
```

普通导出保持 nominal eval 语义：关闭训练 DR 和随机延迟。
若要评估训练地形，必须使用上面带 `--terrain smooth_random_2cm` 导出的 assets。

若需重建训练 NPZ，运行 `uv run python tools/convert_t800_walk.py`。
它将原始 100 Hz 数据转换为 50 Hz，运行 T800 前向运动学并计算速度；
提交的 NPZ 已可直接训练。
